# EchoSight AI

This folder contains the standalone browser demo.

## Run it

1. Open `index.html` in a browser, or use VS Code's Live Server extension.
2. Select **RUN FIRE SIMULATION** to animate targets.
3. Click the camera feed to add a manual target. Use the target-type selector to choose a survivor or hazard.
4. Start the fire simulation to animate targets and unlock spatial audio. Use the top-right audio control to mute or unmute it.

The interface uses Tailwind CSS and Lucide icons from CDNs, so an internet connection is needed for those assets. Target detections are simulated; this demo does not connect to a real camera, thermal sensor, or AI model. Headphones are recommended for stereo panning.
